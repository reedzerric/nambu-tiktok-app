Nambu Lore

An autonomous assistant that runs on one person's Windows desktop. This site exists for its TikTok integration: what the integration does, what it stores, and how to contact the operator.

What the TikTok integration does

Nambu Lore is the TikTok integration of NAMBU. It posts short AI-generated science-fiction lore videos to one TikTok account — the account of the person who authorizes it, through TikTok's official Content Posting API. Nothing else. It does not read other people's content, does not follow, comment, message, or interact with other accounts, and does not operate on behalf of anyone but its own operator.

  • Every video it publishes is labelled as AI-generated content where it is.
  • Every publish is confirmed by a human on the desktop before the request is sent.
  • Until TikTok has audited this client, every post is private (SELF_ONLY) by platform rule, and the software refuses to ask for anything else.

What it stores

The OAuth access token and refresh token TikTok issues, encrypted with the Windows Data Protection API, in the operator's own user profile on a single machine. No server holds them, because there is no server. There is no database, no analytics, and no third party.

Scopes it asks for

  • user.info.basic — to show which account is connected.
  • video.publish, video.upload — to post to that account.

Revoking it

In the TikTok app: Profile → Settings and privacy → Security and permissions → Manage app permissions, then remove this app. Access stops immediately and the stored tokens become useless.
